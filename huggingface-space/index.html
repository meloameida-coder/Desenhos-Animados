🖼️ Biblioteca de personagens

Importe imagens do computador para preparar referências dos seus personagens. Elas ficam guardadas neste navegador. As imagens podem ser baixadas pela própria biblioteca para uso em outros programas.

Formatos aceitos: PNG, JPG ou WebP. Tamanho máximo: 15 MB por imagem.

A prévia da imagem aparecerá aqui.

Importante: esta biblioteca guarda as imagens neste navegador e computador; ainda não sincroniza entre dispositivos. Para importar arquivos diretamente do Google Drive, primeiro baixe-os do Drive para o computador.

📝 Criar um novo projeto

O roteiro-base é montado no navegador a partir do tema e dos personagens; não usa IA externa.

📚 Meus projetos salvos

Os projetos ficam salvos neste navegador. Para sincronizar entre dispositivos, ainda é necessário conectar a autenticação e o banco de dados Supabase.

O backup ajuda a levar os projetos para outro navegador ou computador. Ele inclui os roteiros e dados dos projetos, mas não inclui as imagens da biblioteca de personagens.
