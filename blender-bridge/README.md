# Blender Bridge — Desenhos Animados

Esta pasta prepara a integração local com Blender. O Blender executa no computador do usuário; o site hospedado não consegue iniciar programas no PC sem um conector local.

## Situação
- O agente local e a extensão do Blender serão instalados no Windows.
- A conexão com o botão do site e o envio automático do MP4 ao Supabase ainda precisam ser implementados e testados.
- Não exponha a porta local à internet e não compartilhe tokens.

## Próximo passo
Confirme a versão do Blender e o caminho de instalação no Windows para completar o conector com segurança.
